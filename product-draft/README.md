# Pathshala — preserved product draft

A coaching-institute learning platform pairing teachers (Guru) and students (Kshatra) with scoped AI assistants. The first goal is a reliable loop: evidence → teacher-reviewed plan → student practice → progress → teacher insight.

Status: product discovery and first specification drafted. No application code, cloud infrastructure or production-readiness claims yet. Learning before implementation is deliberate.
