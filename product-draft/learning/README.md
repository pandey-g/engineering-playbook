# Learning contract

The learner drives design decisions. AI explains, challenges assumptions, drafts specs and implements only after the relevant learning gate. Documentation work may continue while a gate is pending. A gate records actual learner answers and an explicit readiness decision; reading a document is not evidence of understanding.

First lesson: `001-tenancy.md`. Start with a 20–30 minute discussion of HTTP requests, authenticated identity, roles, relationships and tenant isolation. Adapt depth to current knowledge, not to an arbitrary quiz score. Use a tiny synthetic example before infrastructure or frameworks. If there is a gap, explain with a counterexample and ask a narrower question.

Later lessons follow the delivery roadmap. Use the skills learning-record template for a small, bounded concept. Keep proposed answers distinct from the learner's own teach-back. Define practical competence: explain the request/data flow, justify a tradeoff, predict a failure, and demonstrate or describe recovery. Absolute mastery of a technology is not a prerequisite for every next step.
