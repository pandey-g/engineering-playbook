# Reusable skills repository

This repository contains reusable engineering workflows, templates and BMAD integration. Product-specific briefs, specs, learning records and architecture decisions belong in the consuming product repository. The existing Pathshala discovery work is temporarily preserved under `product-draft/` at the user's request; keep its product rules scoped there. Future product code and specs belong in a separate repository. Do not make reusable skills depend on an absolute checkout path.

Read `README.md` and choose only the relevant skill. Preserve the consumer's learning-first gate, technology choices and authorization boundaries. Do not infer user approval from generated documents. Framework content in `_bmad/` and generated editor entries is upstream material; customize first-party skills instead. Inspect `frameworks.json` before using version-specific commands. Do not spawn parallel agents or run unattended implementation unless explicitly requested.

Validate each changed skill with the host skill-creator validator when available. Review realistic decision behavior as well as frontmatter. Templates are prompts for substantive decisions, not evidence of completed engineering work.
