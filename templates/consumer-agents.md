Use the relevant installed workflow below. Read its `SKILL.md` before
applying it, and resolve its resource paths relative to that skill folder.

Preserve this project's technology choices, working agreement and authorization
boundaries. Follow its learning agreement: when understanding is required before
implementation, explain the bounded concept, ask for the learner's actual
teach-back, and wait for explicit readiness before dependent implementation.
Generated documents cannot establish the learner's understanding or approval.

Keep product-specific briefs, specifications, decisions, learning records and
validation evidence in this project. Installed templates are starting points;
completed documents and observed checks are separate evidence.

Do not run unattended implementation or parallel agent work unless explicitly
requested. If a referenced skill or resource is missing, report it instead of
claiming to have applied it.
